# SVF → AutoCAD Boundary Automation

This project connects Autodesk APS Viewer (SVF) with AutoCAD
to automatically extract bar lengths from DWG drawings
using externalId mapping.

## Features
- Click in SVF Viewer
- externalId captured
- AutoCAD opens automatically
- Boundary processed
- Bar lengths exported to JSON

## Tech Stack
- Autodesk APS Viewer
- Node.js (Express)
- AutoCAD .NET API
- C#
- JSON Automation
